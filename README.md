# MicroGui

The OpenTAP `MicroGui` is a minimal WPF graphical user interface for running OpenTAP test plans.

### Installation
- Uninstall: `tap package uninstall MicroGui`
- Install: `tap package install MicroGui`
- Run: `tap microgui`

### Installation examples in Windows PowerShell

- Uninstall: `C:\OpenTap\tap.exe package uninstall MicroGui`
- Install: `C:\OpenTap\tap.exe package install "C:\Temp\MicroGui.<version>.TapPackage"`
- Run: `C:\OpenTap\tap.exe microgui`
- Run: `C:\OpenTap\tap.exe microgui "C:\Temp\HelloWorld.TapPlan"`
